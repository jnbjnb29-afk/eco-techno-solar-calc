# Eco_Techno Solar PV Design Calculator

Welcome to the **Eco_Techno Solar PV Design Calculator**! 

This is a professional, integrated engineering tool designed to provide precise calculations for **Off-Grid Solar PV Systems**. It is built strictly following international standards (IEC, NEC, and IEEE).

## Features
- **Comprehensive Load Analysis:** Calculates Day/Night Power and Energy demands.
- **Inverter Sizing:** Selects the correct inverter rating based on safety factors.
- **PV Array Design:** Calculates module counts, string configurations, and temperature-corrected voltage limits.
- **Battery Bank Sizing:** Accurately calculates battery capacity based on Depth of Discharge (DOD) and C-rates.
- **Cable Sizing:** Automated selection of standard cable cross-sections based on IEC 60364-5-52 standards, including voltage drop verification.
- **System Verification:** Comprehensive PASS/FAIL checks to ensure your design is safe and efficient.

## How to Use
1. Enter your project's load data (current, voltage, hours).
2. Input your selected PV Module and Battery specifications.
3. Click **"RUN CALCULATION NOW"** to generate the full technical report.

## Standards Referenced
- IEC 61724, IEC 61427, IEC 61215, IEC 60891
- NEC 690
- IEC 60364-5-52 (Cable Sizing)
